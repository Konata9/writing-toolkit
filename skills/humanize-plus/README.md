# Humanize Plus：深度润色与去 AI 味

对中文文章进行发布前的深度润色，去除 AI 写作痕迹。分两层处理：表层 AI 痕迹（调用 humanizer-zh）和结构性去 AI 味（句长、段高、过渡词等 8 项检查）。

## 使用场景

- 文章写完后、发布前的润色优化
- 检测并修复 AI 生成痕迹
- 改善文章节奏感和活人感
- 写作流程中 humanizer-zh 之后的深度检查

## 检查维度

| 维度 | 说明 |
|------|------|
| 句长方差 | 句子长度是否均匀（AI 特征） |
| 段高方差 | 段落高度是否一致（AI 特征） |
| 过渡词多样性 | 是否过度使用机械过渡词 |
| AI 套话 | 扫描模板句式、开头/结尾套话 |
| 第二人称分布 | "你"字使用是否充分、均匀 |
| 口语插入 | 是否有叙述者声音和主观感受 |
| 总结句 | 是否替读者总结（应删除） |
| 结尾质量 | 结尾是否干净利落 |

## 依赖

- **humanizer-zh**（可选）：处理表层 AI 痕迹。如未安装，跳过表层处理，仍可执行结构性检查。

## 边界与风险

- 润色不是重写，保留原文核心信息、结构和风格
- 不会添加虚假的个人经历或编造的对话
- 历史/科技类内容准确性优先于口语化
- 如果原文已经很自然，不会过度润色

## 与 publish-guard 的关系

humanize-plus 和 [publish-guard](../publish-guard/) 互补：
- 先用 humanize-plus 做文字润色和去 AI 味
- 再用 publish-guard 做平台合规检查
- 两者组合构成完整的发布前流水线
