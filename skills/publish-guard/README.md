# Publish Guard：中文内容平台合规检查

对中文内容进行小红书和微信公众号的平台合规扫描，输出违规报告和修改建议。

## 使用场景

- 在发布小红书笔记或公众号文章前做合规自查
- 新号/高风险账号需要更严格的审核（strict 模式）
- 写作流程中的质量检查环节

## 支持的平台

- **小红书**（`xiaohongshu`）— 最严格，额外检查营销号感和引流触发词
- **微信公众号**（`wechat`）— 额外检查标题安全性和政治评论
- **双平台**（`both`）— 默认模式，同时覆盖两个平台

## 扫描能力

1. **禁用词扫描**（一票否决）：极限词、营销词、政治敏感词
2. **灰色词汇计数**：累计超过 2 个触发限流
3. **最高级替换**：绝对化表述 → 具体描述
4. **外文专有名词检查**：首次出现格式规范
5. **标题安全评估**：标题党检测、要素完整性、政治关联检查
6. **财经与时政类内容检查**：融资/估值/IPO/证券/政策类内容的资质与表述（删文级风险）
7. **AI 生成内容标识检查**：AI 辅助生成内容的显式标识

## 边界与风险

- 本 skill 仅做**检查和报告**，不直接修改内容
- 政治敏感词列表为经验总结，非官方标准；发布前仍应以平台实际审核为准
- 历史引文中的禁用词会标注提醒但不过度修改
- 财经/证券类内容的资质判断（如无资质发布融资/估值/IPO 信息）为经验总结，最终以平台审核为准

## 与 humanize-plus 的关系

publish-guard 和 [humanize-plus](../humanize-plus/) 互补：
- 先用 humanize-plus 做文字润色和去 AI 味
- 再用 publish-guard 做平台合规检查
- 两者组合构成完整的发布前流水线
