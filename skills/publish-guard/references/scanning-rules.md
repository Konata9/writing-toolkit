# 扫描规则与词表

本文件包含 publish-guard 的五类扫描所需的详细规则、词表和判定标准。
当 SKILL.md 中 Step 2 的某个扫描步骤被触发时，读取对应的章节即可。

---

## 一、禁用词扫描

在正文中（排除文末引用出处部分）扫描以下词汇。任何匹配都必须修改。

### 1.1 绝对禁用词

| 禁用词 | 原因 | 替换建议 |
|--------|------|---------|
| `第一`（无范围限定） | 极限词 | 添加限定范围，如"班里第一""部门第一"；或改为"开创性的""领先的" |
| `唯一` | 极限词 | 改为"少有的""为数不多的"；或用具体事实替代断言 |
| `首个` | 极限词 | 改为"早期""较早"；或用具体年份替代（"X 年首次出现"） |
| `世界第一` | 极限+全局范围 | 改为"当时在世界范围内尚属首次"或直接删除 |
| `神器` | 营销词 | 删除，用具体功能描述替代 |
| `必备` | 营销词 | 删除，改为"常用""推荐了解" |
| `爆款` | 营销词 | 删除，改为"受欢迎""传播广泛" |
| `推荐`（无客观依据时） | 营销词 | 删除，或改为"值得了解""可以关注" |
| `天花板` | 极限词 2026 严查 | 改为"高水平""第一梯队" |
| `100%`、`绝对` | 极限词 | 改为"目前来看""在多数情况下" |
| `永久` | 极限词 | 改为"长期""持续" |

### 1.2 全局范围收窄

| 表述模式 | 问题 | 修改方法 |
|---------|------|---------|
| `世界上第一` | 全局断言 | 收窄范围："在当时，还没有人…""在 X 之前，…" |
| `人类历史上第一` | 全局断言 | 收窄范围："在计算机领域""就现有记录来看" |
| `全世界最` | 全局+最高级 | 改为具体比较："比同期其他…更快""在同类中表现突出" |

### 1.3 平台特有禁用词

**小红书特有（更严格）**：
- `震惊`、`速看`、`删前速看`、`一定要看` — 营销号感
- `私信我`、`加微信`、`关注公众号`、`链接在简介` — 引流触发
- `下单`、`官网`、`app`（在引导语境中）— 引流触发
- `黑客`（在安全事件语境中）— 安全敏感，改为"安全研究人员""白帽"
- `攻击`（在安全事件语境中）— 改为"利用了""绕过了""测试了"
- `劫持`、`入侵` — 改为"未经授权访问""控制了"
- `漏洞`（在攻击步骤语境中）— 改为"问题""缺陷""疏漏"

**公众号特有**：
- 误导性标题（标题与内容严重不符）— 有删文风险
- 政治评论（即使是对历史背景的评论也要避免）

### 1.4 政治敏感词（极高风险）

以下词汇在正文中出现时，除非是引述历史原文且无法避免，否则必须改写或删除：

**绝对不可出现**：
- 中美关系框架：`中美`（并列出现时）、`中国 vs 美国`、`对抗`
- 政治制度：`选举`、`政府`（作为政治实体时）、`政党`、`意识形态`
- 军事安全：`军事`、`武器`、`间谍`、`情报`（国家安全语境）
- 外国政治实体：`CIA`、`FBI`（或其他国家情报机构）
- 敏感地区：`台湾`、`香港`（非旅游语境）、`新疆`、`西藏`（政治语境）
- 极端标签：`法西斯`、`威胁论`、`舆论战`
- 政治操作暗示：`暗钱`、`黑金`

**高风险词**（尽量避免，如需使用需谨慎处理）：
- `政治` — 广泛触发，尽量用"政策方向"替代
- `伊朗`、`俄罗斯` — 争议地区政治实体，仅作事实提及、不展开评价
- `抹黑` — 冲突叙事，改为"负面描述""不实信息"
- `革命性`、`颠覆` — 夸大宣传，改为"有意思的变化""值得关注"

**原则**：描述意义，而非断言排名。用具体细节替代价值判断。

## 二、灰色词汇扫描

灰色词汇不算绝对违规，但在正文中累计超过 2 个会触发限流。扫描并计数。

### 2.1 灰色词汇列表

| 灰色词汇 | 替换建议 |
|---------|---------|
| `顶级` | "高水平""头部""领先的" |
| `极致` | "追求细节""做到很好" |
| `完美` | "出色""优秀""高质量" |
| `无敌` | "突出""出色" 或直接删除 |
| `震撼` | "令人印象深刻""引人注目" |
| `惊艳` | "出色""引人注目""让人眼前一亮" |
| `炸裂` | "非常出色""效果很好" |
| `曝光` | "披露""揭示""公开" |
| `揭秘` | "解析""介绍""讲述" |
| `内幕` | "背后故事""内部细节" |

### 2.2 计数规则

- 扫描正文（不含引用出处）
- 每出现一个灰色词汇计数 +1
- 同一词汇出现多次计多次
- 如果总数 > 2：保留最重要的 2 个，其余替换
- 如果总数 ≤ 2：通过，但标注提醒

## 三、最高级替换

扫描所有"最 + 形容词"的绝对化表述。这些不需要一票否决，但需要评估并替换为具体描述。

### 3.1 常见最高级表述

| 表述 | 替换方法 |
|------|---------|
| `最大` | 改为具体数字："拥有 X 名员工"；或相对描述："规模领先的" |
| `最快` | 改为具体数据；或"当时速度领先的" |
| `最先进` | 改为具体技术指标；或"代表了当时最高水平" |
| `最强大` | 改为具体能力描述；或"在 X 方面能力突出" |
| `最重要` | 改为"影响深远的""关键的"；或用具体事实说明重要性 |
| `最高` | 改为具体数字；或添加限定范围 |
| `最年长` | 如属历史事实且有来源支持可保留；否则改为"年长的" |
| `最早` | 如属确凿历史事实且有至少 2 个独立来源可保留 |

### 3.2 评判原则

- 如果最高级表述有**两个以上独立来源**支撑且属于**可验证的历史事实**，可以保留
- 如果最高级表述是主观判断或缺少充分来源，必须替换
- 能用具体数字替代的，优先用数字

## 四、外文专有名词检查

扫描正文中所有外文人名、地名、机构名、公司名的首次出现格式。

### 4.1 基本规则

**首次出现**：`中文译名（English Original）`
**后续出现**：中文简称，或公认缩写

| 类型 | 首次出现格式 | 后续使用 | 示例 |
|------|------------|---------|------|
| 人名 | 中文全名（English Name） | 中文姓氏 | "史蒂夫·乔布斯（Steve Jobs）"→"乔布斯" |
| 机构/学校 | 中文全名（English Name） | 中文简称 | "瓦萨学院（Vassar College）"→"瓦萨学院" |
| 公司 | 中文全名（English Name） | 中文简称 | "雷明顿兰德（Remington Rand）"→"雷明顿兰德" |
| 地点/建筑 | 中文全名（English Name） | 中文 | "摩尔学院（Moore School）大楼" |
| 组织 | 中文全名（Abbreviation） | 缩写可接受 | "计算机协会（ACM）"→"ACM" |

### 4.2 可以保留原文的情况

- 编程语言名称：COBOL、FORTRAN、A-0 等
- 产品/架构代号：无标准翻译时保留，如"Hopper 架构"
- 论文/书名：引用原文时保留英文标题
- 铭牌/碑文引用：保持原文
- 公认缩写（首次出现后）：ACM、MIT、IBM、CBS
- 无建立翻译的公司名：OpenAI、Anthropic、Meta

### 4.3 扫描流程

1. 找出正文中所有英文单词/名称
2. 判断是否属于可保留原文的例外
3. 不属于例外：检查首次出现是否使用了 `中文（English）` 格式
4. 检查后续出现是否使用了中文简称
5. 报告违规项

## 五、标题安全评估

### 5.1 公众号标题

公众号标题的合规检查要点：

- [ ] **无敏感词**：检查是否包含禁用词列表中的任何词汇
- [ ] **准确性**：标题是否准确反映正文内容（标题党有删文风险）
- [ ] **要素完整性**：是否包含以下三要素中的至少两项：
  - 具体数字
  - 问句钩子（引发好奇心）
  - 核心冲突暗示
- [ ] **无政治关联**：即使正文是历史题材，标题也不应暗示政治评论

### 5.2 小红书标题

小红书标题的合规检查要点：

- [ ] **无禁用词**：检查全部禁用词
- [ ] **无营销号感**：没有"震惊""速看""必读"等
- [ ] **有搜索关键词**：标题中是否包含用户会实际搜索的词
- [ ] **无极端表述**：不使用"最""第一""唯一""天花板"
- [ ] **长度适中**：建议 10-25 字，移动端完整显示
- [ ] **备选标题**：建议准备 1-2 个备选以防限流

### 5.3 特殊处理

对于历史俗称在标题中的使用：
- 如"八叛逆"（仙童半导体历史名词）→ 标题中改用中性表述，如"仙童半导体的传奇起点"
- 如涉及争议历史，建议先用草稿功能测试限流

## 六、财经与时政类内容

本节规则用于识别会导致**删文**（而非仅限流）的高风险内容。删除通知通常为「涉嫌违反相关法律法规和政策，已删除」。这类内容即使通过词汇级扫描，仍可能因**内容品类资质**或**表述方式**被删。

### 6.1 法律依据

| 法规 | 关键点 |
|------|--------|
| 《互联网新闻信息服务管理规定》（国信办 2017） | 第 2 条："新闻信息"含政治、经济、军事、外交等社会公共事务的报道评论；第 5/22 条：未经许可不得提供互联网新闻信息服务 |
| 《证券法》第 120 条等 | 证券投资咨询、涉证券信息发布需经核准 |
| 《网络信息内容生态治理规定》（2020） | 第 7/8 条：违法违规信息与应防范抵制信息 |
| 《人工智能生成合成内容标识办法》（2025-09-01 施行） | AI 生成合成内容须加显式标识与隐式标识 |

### 6.2 财经信息资质触发词

以下词出现时，检查是否以**断言口吻**陈述、且账号是否具备相应资质（个人号/普通号默认无资质）：

- **融资/估值类**：融资、募资、估值、投前、投后、Pre-A/A/B/C 轮、美元基金、人民币基金、战投、基石投资
- **上市/证券类**：IPO、上市、科创板、创业板、北交所、港交所、纳斯达克、美股、A股、市值、股价、市盈率、招股书、路演、打新
- **证券投资类**：荐股、涨停、牛股、妖股、收益预测、目标价、买卖建议、加仓、抄底
- **基金/资管类**：公募、私募、量化、对冲、净值、年化收益、回撤、业绩报酬

### 6.3 判定标准

| 表述方式 | 判定 | 处理 |
|---------|------|------|
| 断言式："DeepSeek 估值约 ¥5000 亿""重启 $80 亿融资" | ❌ 高风险 | 改为"据 Reuters 报道，投前估值约 ¥5000 亿" |
| 转述式："据 Reuters 报道…""彭博社称…" | ✅ 通过 | 保留，但须信源真实可查 |
| 无信源前瞻/内部信息："IPO 文件正在起草""正操盘""即将上市" | ❌ 高风险 | 删除，或改为"有分析认为/据称" |
| 荐股/收益预测/买卖建议 | ❌ 一票否决 | 直接删除 |

### 6.4 事实与推测分家判定

- 一句话去掉信源标记后，若无法判断是"可核实事实"还是"作者观点/推测"，即违规。
- "业内估算""有分析认为""据称"等估测内容，不得与已核实事实在同一句或同一段平铺直叙。
- 公司未公开的内部决策、未来计划、财务数据，一律视为推测。

### 6.5 信息来源标注

- 关键数据首次出现处就地标注"来源：媒体/机构全称"（如"来源：Reuters""来源：36氪"）。
- 禁止"网传""网友表示""据消息""业内人士""据透露"等模糊来源。
- 涉及时事/公共政策/社会事件，须标注官方账号（如"来源：国家网信办"）。

### 6.6 时政/政策话题边界

- 涉及政府机构、监管政策、国家战略时，仅做事实转述，不做评价、预测、质疑。
- 政策类话题（出口管制、芯片管制、数据安全、产业基金、行业整治）避免引申评论。
- 标题避免"国家/政府 + 动作"的暗示性表述。

### 6.7 改写模板

| 原文（高风险） | 改写（合规） |
|---------------|-------------|
| DeepSeek 重启 $80 亿融资，投前估值约 ¥5000 亿 | 据 Reuters 报道，DeepSeek 重启约 $80 亿融资，投前估值约 ¥5000 亿 |
| 科创板 IPO 的文件正在起草 | 多家外媒报道称，DeepSeek 拟赴科创板上市 |
| 涨价是为了给融资和 IPO 铺路 | 有分析认为，涨价或有助于改善单位经济模型，为其融资与上市计划提供支撑 |
| 这只股票必然大涨 | （删除） |

### 6.8 案例警示

2026 年一篇关于某 AI 公司"API 涨价 + 融资 + IPO"的文章被公众号以「涉嫌违反相关法律法规和政策」删除。复盘结论：数据本身多源交叉验证无误，但（1）融资/估值/IPO 属经济类新闻信息，无资质发布构成主因；（2）"IPO 文件正在起草"等推测以断言口吻呈现；（3）标题与导语观点化叙事放大风险。凡出现 6.2 触发词的内容，必须执行本章检查。

## 七、AI 生成内容标识

### 7.1 规则

- 《人工智能生成合成内容标识办法》（2025-09-01 施行）：AI 生成合成内容须加显式标识（用户可见）与隐式标识（元数据）。
- 适用于所有平台、所有内容类型，与主题无关。
- 微信《运营规范》4.24.2 明确要求：发布生成式 AI 生成合成内容须显著标识。

### 7.2 检查要点

- 内容是否由 AI 辅助生成（含 AI 初稿 + 人工润色）？
- 是否已添加显式标识（如"本文部分内容由 AI 辅助生成"）？
- 未添加 → 标记高危，建议在文首或文末补充声明。

### 7.3 建议措辞

- "本文部分内容由 AI 辅助生成，并经人工核对与润色。"
- "文中引用数据均来自公开报道，AI 仅参与文字组织。"
