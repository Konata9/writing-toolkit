# Story Write：故事化写作

基于调研资料，用"故事化"手法撰写中文科普/历史类长文初稿。覆盖标题设计、导读块、开篇钩子、叙事技法、AI 痕迹规避和小红书配文。

## 使用场景

- research 完成后，把可靠事实写成故事
- 用户要求写故事 / 故事化写作 / 根据调研写文章时
- 作为写作流程的核心写作步骤

## 能力

- 标题设计：8 种公式 + 三要素 + 新鲜度测试
- 导读块 + 开篇钩子（导读为必选）
- 12 条叙事技法（阻力才是故事、人物锚点、情绪弧线、数字武器化等）
- AI 痕迹排查（禁用套话、模板句式、段落节奏、人名规范）
- 小红书配文生成

## 输入参数

| 参数 | 说明 | 必填 |
|------|------|------|
| `research` | 调研资料 | ✅ |
| `structure` | 结构模板（未传则用默认 7 段式） | 可选 |
| `length` | 篇幅红线 | 可选 |

## 边界与风险

- 只写初稿，不润色、不合规——润色（humanize-plus）和合规（publish-guard）由主编排技能随后调用
- 不虚构：所有事实以 research 为准，不编造对话、场景、心理活动
- 结构模板和篇幅由各项目传入，本技能保持领域无关

## 在写作流水线中的位置

```
source-verify（验证事实） → story-write（写初稿） → humanize-plus（润色） → publish-guard（合规）
                                └── image-sourcing（配图，可并行）
```
