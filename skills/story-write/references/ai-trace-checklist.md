# AI 痕迹排查清单

本文件包含 story-write 写作后自检所需的 AI 痕迹排查规则。撰写完成后逐项检查。

---

## 一、禁用短语（正文中不应出现）

- `众所周知` / `不言而喻` / `毋庸置疑`
- `在……的时代背景下` / `随着……的发展`
- `从某种意义上说` / `不可否认的是` / `值得深思的是`
- `在这个信息爆炸的时代` / `近年来，……`

## 二、模板句式（减少使用）

- `不仅……而且……` → 用具体并列替代
- `虽然……但是……` → 直接写转折
- `一方面……另一方面……` → 每个"方面"展开写一段
- `既……又……` → 用具体描述替代
- `通过……从而……` / `在……的同时`

## 三、三段式法则（避免）

AI 常见的"三段式"结构，用叙事而非枚举替代：

- ❌ "XXX 有三个特点：第一……第二……第三……"
- ❌ "从 A 到 B 再到 C"
- ❌ "首先……其次……最后……"

## 四、夸张象征 / 模糊归因

- ❌ "这不仅是历史的转折点，更是人类文明的涅槃重生"
- ❌ "历史学家普遍认为" / "学界公认"
- ✅ 具体归因："斯塔夫里阿诺斯在《全球通史》中写道"

## 五、句式与节奏（手机屏幕优先）

- **段落不超过 150 字**（约手机半屏），超过的拆分
- 长短句交错：避免连续 3 句以上长度相近
- 段落高度方差：避免连续多段长度相近；连续 3 段超 120 字要插入短段落或单句重击
- 单句成段（重击）每 8-10 段穿插一处，全文 5-8 处

## 六、过渡词去重

机械过渡词每个出现不超过 2-3 次：

- `然而` / `但是` / `因此` / `此外` / `与此同时` / `另一方面` / `综上所述`
- 鼓励删除 50% 以上过渡词，很多删掉后反而更自然

**自然替代**：`说白了` / `好在` / `有意思的是` / `那时候` / `可惜` / `偏偏` / `没想到`

## 七、外文人名/地名/机构名规范

首次出现：`中文译名（English Original）`；后续：中文简称。

| 类型 | 首次 | 后续 |
|------|------|------|
| 人名 | 史蒂夫·乔布斯（Steve Jobs） | 乔布斯 |
| 机构 | 瓦萨学院（Vassar College） | 瓦萨学院 |
| 公司 | 雷明顿兰德（Remington Rand） | 雷明顿兰德 |

**间隔号用 `·`（U+00B7），不用 `-`。**

**可保留原文的例外**：编程语言名（FORTRAN、Python）、产品代号、论文/书名、公认缩写（ACM、MIT）、无中文名的公司（OpenAI）。

## 八、克制格式化

- 加粗：一篇文章 2-3 处，不要满篇加粗
- 长破折号：不超过 3 个
- 感叹号：不超过 2 个
- 正文不使用 emoji（小红书配文除外）
- 中文引号用「」或""，不混用中英文引号

## 九、结尾质量

不合格结尾（应避免）：

- 拔高式："这不仅是 X 的故事，更是人类 Y 精神的体现"
- 总结式："综上所述，X 对 Y 产生了深远的影响"
- 鸡汤式 / 生硬互动 / 预告式

合格结尾：具体细节收尾、戛然而止、回到开篇意象形成闭环。

## 十、替读者总结句扫描

扫描模式：`这说明……` / `这意味着……` / `可以看出……` / `由此可见……` /
`不难发现……` / `这反映出……` / `这标志着……`

删除这些总结句。读者不需要你替他们总结。
