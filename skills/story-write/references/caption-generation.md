# 小红书配文生成规范

本文件包含 story-write 的小红书配文（caption）生成规则。

---

## 何时生成

文章正文初稿完成后，生成独立的 `xhs-caption.md`。小红书配文是**独立的内容产品**，
不是公众号的缩略版。

---

## 格式规范

| 规则 | 说明 |
|------|------|
| **标题** | ≤20 字，有钩子有数字/对比，无敏感词，不照搬公众号标题 |
| **长度** | 200-450 字 |
| **开头** | 场景、矛盾或问题切入——不要用"今天给大家介绍…" |
| **主体** | 3-5 个惊人事实/数字/对比，每行一句，短行排列 |
| **引语收尾** | 以人物原话或有共鸣的观察收尾（非"替读者总结"） |
| **标签** | 3-6 个，`#标签` 格式，空格分隔 |
| **可扫读性** | 短行、关键数字突出、无密集段落 |

---

## 文件格式

```markdown
[标题 — ≤20 字，独立一行]
[caption 正文 — 换行后直接开始]

#标签1 #标签2 #标签3
```

---

## 与公众号版本的区别

| 维度 | 公众号版本 | 小红书配文 |
|------|-----------|-----------|
| 作者身份 | 博学的朋友在讲故事 | 跟你聊天的同行/爱好者 |
| 句式 | 叙事段落 | 短句，一句一行 |
| 结尾 | 呼应开头/对比收束 | 人物原话/留白观察 |
| 目标 | 让人获得"原来如此"的惊喜 | 让刷到的人停下来读完这 300 字 |

---

## 合规检查（保存前）

- [ ] 标题 ≤20 字且无敏感词
- [ ] 无极限词（`第一` 无范围限定、`首个`、`唯一`、`世界第一`）
- [ ] 灰色词汇 ≤ 2 个（`顶级`/`极致`/`完美`/`震撼`/`惊艳` 等）
- [ ] 外文专有名词使用中文（编程语言名、公认缩写除外）
- [ ] 标签前的最后一行是引语或事实，不是"替读者总结"
- [ ] 配文后续应通过 `humanize-plus`（casual 模式）和 `publish-guard`（小红书模式）——由主编排技能调用
