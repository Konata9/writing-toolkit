# 默认结构模板与导读块规范

本文件包含 story-write 的默认结构模板（未传 `structure` 参数时使用）和导读块规范。

---

## 一、默认结构模板（通用 7 段式）

```
┌─ 导读块（100-150 字）──────────────────┐
│ 提炼全文核心矛盾/反差                   │
│ 至少一个具体数字 + 一个悬念钩子         │
│ 块引用格式（> 开头），不是小标题        │
├─ 开篇钩子（150-250 字）────────────────┐
│ 具体场景切入（时间+地点+人物+动作）      │
│ 立刻建立冲突或错位感                   │
├─ 背景（2-3 段）───────────────────────┤
│ 织入叙事，不写成干巴巴的说明            │
├─ 人物故事（3-5 段）───────────────────┤
│ 谁创造了这个，为什么是他               │
├─ 核心过程（3-5 段）───────────────────┤
│ 关键决策、突破、挣扎                   │
├─ 影响与遗产（2-3 段）─────────────────┤
│ 直接后继、对今天的影响                 │
├─ 结尾（1-2 段）───────────────────────┤
│ 呼应开头，收束                        │
└─────────────────────────────────────┘
```

> 各项目的结构模板由主编排技能作为 `structure` 参数传入并覆盖此默认模板。
> 段与段之间用过渡句桥接：一句收束上一段，一句开启下一段。

---

## 二、导读块规范（必选）

导读块是标题和正文之间的"电影预告片"。它解决一个核心问题：读者在信息流中
看到标题点进来后，前 3 秒决定"继续读还是划走"。**没有导读块 = feed 流直接展示
正文开篇 = 浪费唯一的钩子展示位。**

### 位置

`# 标题` 之后、正文开篇之前，一个独立的引用块（blockquote）。

### 格式

```markdown
> [100-150 字，提炼全文最核心的矛盾/反差]
```

### 写法（三要素）

1. **一个具体、令人意外的数字或事实** —— 让读者"真的吗？"
2. **文章的核心矛盾/反差** —— 让读者"为什么会这样？"
3. **一句暗示结局但不剧透的钩子** —— 让读者"我得看看"

### 示例

```
> 公元前 2070 年，黄河边，大禹正在挖泥巴。他要治水。
> 同一时间，尼罗河边，胡夫金字塔已经站了 490 年。
> 更狠的是：当夏朝夯土宫殿化为尘土时，金字塔还在。但这不是「落后」的故事——
> 中国人把永恒藏在了制度里，而不是石头上。
```

### 诀窍

- 用短句。每一句话都应可独立传播
- 导读块看完直接接开篇场景，两者之间不要有额外过渡
- 导读块不是文章摘要，不告诉读者"本文将讲 X"，而是让读者想"X 是怎么回事"

---

## 三、篇幅红线

- 篇幅由主编排技能的 `length` 参数传入；未传时默认 2000-3500 字
- 不足下限：扩展最薄弱的段落，优先扩展故事性（人物困境、具体细节）
- 超出上限：压缩纯描述性内容，而非核心故事
- 引用出处、图片来源声明不计入正文字数

---

## 四、开篇与导读的区别

| | 导读块 | 开篇 |
|---|--------|------|
| 职责 | 预告片（勾住 3 秒） | 正片（第一个场景） |
| 内容 | 矛盾提炼 + 数字 + 悬念 | 时间+地点+人物+动作 |
| 关系 | 先于开篇 | 直接承接导读，两者内容不重复 |

---

## 五、小标题 = 微型悬念

小标题是滑屏读者的"续读开关"，本身要是一个钩子，不是目录标签。

- ❌ "背景介绍" / "发展历程" / "第二部分"
- ✅ 用具体数字、时间、反转或口语做标题：「两个人，一间办公室，半年不到」「我是抄 Simula 作业长大的」

要么抛出悬念（"半年不到"——不到半年干了什么？），要么给一个可独立记忆的意象（"抄作业长大"）。禁止把 7 段式模板里的「背景 / 人物故事 / 核心过程」原样当标题。

---

## 六、前情提要（连载内容必选）

上/下篇连载时，在导读块之后、开篇之前加 2-4 行「前情提要」，让第一次刷到的读者也能 3 秒接上剧情：

- 只保留上一篇的因果链：谁、在何时、做了什么、导致了什么现状
- 结尾用一句反转或悬念，把读者引到本篇的冲突（"然后泡沫破了。"）
- 老读者可快速略过，新读者不至于因缺上文而划走
