# 来源验证规则

本文件包含 source-verify 的详细规则：来源优先级阶梯、独立性判断、星级评级表、记录格式、异常标记约定。

---

## 一、来源优先级阶梯

| 优先级 | 来源类型 | 示例 |
|--------|---------|------|
| 1（最高） | 学术出版物 | 同行评审论文、大学出版社专著 |
| 2 | 官方/一手资料 | 官方文档、原始论文、博物馆馆藏、国家档案 |
| 3 | 权威参考 | 大英百科全书、专业机构官网（博物馆/学会）、权威媒体 |
| 4 | 百科 | Wikipedia（仅起点，不可作唯一来源） |
| 5（最低） | 个人内容 | 个人博客、论坛帖子（一般不引用） |

---

## 二、独立性判断

交叉验证要求"2 个独立来源"。判断是否独立：

| 情况 | 是否算 2 个来源 |
|------|----------------|
| 两个不同机构各自发布 | ✅ 是 |
| 同一页面不同段落 | ❌ 否 |
| 两个自媒体互相抄袭 | ❌ 否 |
| Wikipedia 引用了论文 A，同时直接引用了论文 A | ✅ 是（一手 + 转述） |

---

## 三、星级评级表

| 星级 | 含义 | 典型来源 |
|------|------|---------|
| ⭐⭐⭐⭐⭐ | 同行评审 / 一手档案 / 官方规范 | 学术期刊、博物馆馆藏、官方文档 |
| ⭐⭐⭐⭐ | 权威参考 / 详细专著 | 大英百科、专业机构官网、学术专著 |
| ⭐⭐⭐ | 百科 / 主流媒体 | Wikipedia、Britannica、正规媒体 |
| ⭐⭐ | 一般网络来源 | 博客、论坛（仅作参考） |
| ⭐ | 来源不明 | 避免使用，除非明确标注 |

---

## 四、记录格式（供调用方写入 research.md）

本 skill 只输出验证报告，**不直接修改 research.md**。以下格式是给调用方
（主编排技能）据报告将结果回填到 research.md 时的建议模板：

```markdown
- **事实**：[事实描述]
- **来源**：[主来源名称]，[URL]
- **佐证**：[交叉验证来源名称]，[URL]
- **状态**：✅ 已验证 / ⚠️ 待验证 / ❌ 争议
```

---

## 五、异常标记约定

| 标记 | 含义 |
|------|------|
| `[unverified]` | 单一来源，未交叉验证，不进正文 |
| `[source unavailable]` | 搜索失败，无法验证，不进正文 |
| `⚠️ 待验证` | 同 unverified，中文项目常用 |
| `⚠️ 学界争议` | 来源矛盾，正文采用权威源 |

---

## 六、特殊判定

- 历史类"最早 / 首个 / 第一"等断言：需 2+ 独立来源且属可验证历史事实，否则视为未验证
- 年代冲突：取学术共识，在 research.md 注明争议
- 有争议的敏感表述：采用通说，标注"据传"或"学界有争议"
