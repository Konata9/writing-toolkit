# Source Verify：事实交叉验证与来源可靠性评级

对文章创作前的调研事实进行交叉验证和来源可靠性评级，输出结构化验证报告。

## 使用场景

- 调研完成后、动笔写作前，对 research 中的关键事实逐条验证
- 用户要求 fact-check / 交叉验证 / 核实资料时
- 写作流程中作为调研与写作之间的质量关卡

## 验证能力

- 交叉验证：每个关键事实至少 2 个独立来源
- 来源优先级判定：学术 > 一手 > 权威参考 > Wikipedia > 个人内容
- 可靠性星级评级（1-5 星）
- 独立来源判断（识别互相抄袭的假"两个来源"）
- 结构化验证报告输出

## 边界与风险

- 只做验证和报告，不直接修改 research.md（由调用方根据报告修改）
- 不判断"哪些算关键事实"的领域标准——由各项目的调研技能传入
- 数据源清单（该领域用哪些权威源）由调用方提供

## 与 story-write 的关系

source-verify 和 [story-write](../story-write/) 互补：

- 先用 source-verify 确保 research 事实可靠
- 再用 story-write 把可靠事实写成故事
- 两者组合构成"调研 → 写作"的质量链条
