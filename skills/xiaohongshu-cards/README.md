# Xiaohongshu Cards：小红书图文卡片生成器

把用户给的素材（博客文章、草稿、大纲）制作成可直接发布的小红书图文卡片（贴图）与配套笔记文案。

**核心模型：引擎固定、风格可变。** 卡片版式是引擎（不变量），配色/字体/背景是风格预设（变量）；换风格只换皮。

## 使用场景

- 把一篇博客/草稿改写成小红书图文卡片
- 为某个主题生成 6–8 张一套的小红书贴图 + 笔记文案
- 为已有内容做"贴图化"，并保持稳定的系列视觉风格

## 工作流

```
素材 → 补充内容(+source-verify) → 确定风格(选/研) → 生成卡片
     → 反 AI 味自检(仅给建议) → 确认后修改
```

1. **收素材**（强制）：必须由用户提供，否则停下索要。
2. **补充内容**：询问官方文档 / 图片需求 / 事实校验；校验走 `source-verify`，配图走 `image-sourcing`。
3. **确定风格**：查风格登记表；命中 → 让用户选；未命中 → 检索分析小红书高分笔记 → 出预设草案 → 确认后登记。
4. **生成卡片**：选叙事骨架 → 拆 6–8 卡 → **先出大纲确认** → 套预设 token + 填模板 → 导出 1080×1440 PNG + 写文案。
5. **反 AI 味自检**：按 `references/anti-slop.md` 逐条核对，输出**建议报告**（真该改 / 本风格豁免），不改文件。
6. **确认后修改**：用户勾选后再改，只重导出受影响卡片。

## 先出大纲再出图

第 3 步确定后、正式出图前，先给「标题候选 + 每图要点」请用户确认，避免整套返工。

## 风格预设

- 已登记：**科技风 · 电光钴蓝**（`references/styles/tech-cobalt.md`）。
- 新增风格：按 `references/styles/_index.md` 的方法在小红书调研 → 产出预设 → 确认后登记。

## 反 AI 味自检

`references/anti-slop.md` 是一套**卡片视角**反 AI 味规则（区别于网页视角）：emoji、大字、系列角标、等宽标签等属平台原生或刻意选择，列为**豁免**；真正的问题（编造数据、模板感、文字墙、渐变氛围、雾状阴影等）列为**建议**。**只给建议，用户确认后才改。**

## 依赖

- 事实校验：`source-verify`（可选）
- 配图：`image-sourcing`（可选）
- 文案去 AI 味：`humanize-plus`（可选）
- 平台合规：`publish-guard`（可选）
- 渲染：Playwright（MCP 或本地 `npx playwright`）

> 缺失 Playwright 时**停止导出**并提示安装，不伪造图片或结果。

## 安装

```bash
npx skills install Konata9/writing-toolkit/xiaohongshu-cards
```

## 边界

- 素材必须由用户提供，不编造内容。
- 禁止编造数据；`source-verify` 标为 `[unverified]` 的事实不进卡片。
- 正文不放外链；发布需勾选「AI 生成内容」声明。
- 反 AI 味检查为**建议**，不自动修改。
