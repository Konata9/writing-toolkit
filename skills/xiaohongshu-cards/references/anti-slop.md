# 卡片向「反 AI 味」规则集

> 提炼自通用反 slop 方法论，但**改用社交卡片视角重写**——网页 slop 与卡片 slop 部分相反。
> **定位：自检建议。** 生成后逐条核对 → 出建议报告 → 用户确认后**才**修改。定位为软建议，不是硬门禁（除下方「硬规则」）。

---

## 0. 视角说明（为什么不能照搬网页规则）

**网页会报、卡片应保留的**（见豁免清单）：emoji、大字号短标题、系列角标、等宽标签、功能 pill、统一封面模板、适度高亮。

**卡片独有、网页没有的 slop**：
- 模板感（每卡同节奏、读不出焦点）
- 文字墙 / 信息过载 / 填充卡
- 封面无钩子、标题党无兑现
- **系列风格漂移**（社交卡片最致命的机器感）

**两者共识、贯穿硬规则**：禁止编造数据；颜色/字体纪律；对比度；不过度装饰；无假对比文案。

## 1. 视觉风格（AI 生成感）

| # | 信号 | 为什么像 AI | 建议 |
|---|------|-------------|------|
| 1.1 | 紫蓝渐变 / 渐变网格氛围底 | 训练集默认审美 | 扁平单色底 + 发丝线 |
| 1.2 | 发光光晕、neon glow、3D 光球 | 廉价未来感 | 删除光晕 |
| 1.3 | 玻璃拟态 + 超大圆角卡片 | 模板默认 | 实色 + 小圆角 |
| 1.4 | 超大弥散投影（模糊范围 ≫ 元素） | 雾状，不成比例 | 收紧为贴合阴影 |
| 1.5 | 图标色块 / 同色 tint 图标 | 图标缸 | 去色块，随文字色 |
| 1.6 | 单图 ≥3 主色、高饱和多色 | 无主次 | 收到 1 accent + 1 highlight |
| 1.7 | 无意义贴纸、装饰性闪点/箭头 | 堆装饰 | 删 |
| 1.8 | 默认「渐变文字」大标题 | 典型 AI tell | 纯色字，靠字号/层级 |
| 1.9 | AI 生成插画 / 3D 手 / 机器人当填充图 | 一眼生成 | 用真实截图或干脆不放 |

## 2. 版式（模板感）

| # | 信号 | 为什么像 AI | 建议 |
|---|------|-------------|------|
| 2.1 | 每卡同一节奏、每块等重、**无焦点** | 机器匀速输出 | 每卡一个主角，权重分明 |
| 2.2 | 卡中卡（多 surface 各带边框+圆角+阴影） | 层层套 | 内层用发丝线，去一处 surface |
| 2.3 | **装饰性编号**（非真实序列） | "01/02/03" 套路 | 只给真实序列编号；装饰编号改语义或删 |
| 2.4 | 每卡都有无意义 kicker/角标 | 复读标题 | 让角标承载真实维度（分类/序号）；否则删 |
| 2.5 | 一图多观点（信息过载） | 贪多 | 一图一观点，拆卡 |
| 2.6 | 文字墙（单卡 >60 字、无呼吸） | 降低完读 | 拆短句、分行、留白 |
| 2.7 | 字号层级扁平（标题≈正文，步进 <1.25×） | 靠灰度撑层级 | 拉开字号步进 |
| 2.8 | 全部居中 + 每段同间距 | 无关系区分 | 按关系分配间距 |

## 3. 文案（AI 腔）

| # | 信号 | 为什么像 AI | 建议 |
|---|------|-------------|------|
| 3.1 | 「不是 X，而是 Y」假对比 | 固定句式 | 直说 Y，除非否定纠正真误解 |
| 3.2 | 假深度金句/格言 | 空洞拔高 | 说具体的事 |
| 3.3 | 工整排比堆叠（三连/四连） | 机械节奏 | 打散，长短句交错 |
| 3.4 | 空泛宣传词（赋能/颠覆/极致/一站式/拿捏） | 大词 | 具体动词 |
| 3.5 | **过度** emoji 堆砌 | 不是用 emoji，是 spam | 功能化，克制 |
| 3.6 | 营销号腔（家人们/宝子们/不看后悔/码住） | 与真人分享冲突 | 平视口吻 |
| 3.7 | 夸大/绝对化（最/第一/唯一/100%/永久） | 违规+AI 味 | 具体描述或删 |
| 3.8 | **编造数据**（数字/用户量/百分比无来源） | 破坏信任 | 见 SKILL.md 硬规则 2 · 删或标注待补 |
| 3.9 | 术语不一致 / 无必要中英夹生 | 机器拼贴 | 统一术语，术语保留英文即可 |

## 4. 系列一致性（卡片独有）

| # | 信号 | 为什么像 AI | 建议 |
|---|------|-------------|------|
| 4.1 | 各卡字体/配色/边距**漂移** | 不成系统 | 严格用预设 token |
| 4.2 | 封面模板不统一，不形成辨识度 | 无系列感 | 固定封面模板 |
| 4.3 | 每卡**完全等高完全没有节奏** | 死板 | hook 卡/内容卡/总结卡应有轻重差 |
| 4.4 | 命名/术语不统一 | 不专业 | 建术语表 |

## 5. 可读性与合规

| # | 信号 | 建议 |
|---|------|------|
| 5.1 | 缩略图/50% 下不可读（字号小、对比低） | 缩小预览自检 |
| 5.2 | 核心信息落在安全区外（底部 150px、四角） | 移到中上 2/3 |
| 5.3 | 外链/引流触发 | 改"搜名字"+ 评论区引导 |
| 5.4 | AI 生成未声明 | 发布勾选声明 |

## 6. 封面（feed 特有）

| # | 信号 | 建议 |
|---|------|------|
| 6.1 | 3 秒说不出价值 | 一句话强承诺 + 大字 |
| 6.2 | 标题党无兑现 | 承诺与内容一致 |
| 6.3 | 纯图无信息 / 纯文字无设计 | 信息 + 设计并重 |
| 6.4 | 封面与内容不符 | 一致 |

## 豁免清单（网页会报、本类内容应保留）

以下属**平台原生或刻意选择**，自检时报为「本风格豁免」，**保留**：
1. **适量 emoji** —— 小红书平台原生语气（区别于 3.5 的"堆砌"）。
2. **大字号短标题** —— 封面就是要大字（区别于 2.7 的"层级扁平"；是短词而非整句）。
3. **系列角标 / 真实序列编号** —— 承担系列导航与真实顺序（区别于 2.3/2.4）。
4. **等宽标签（mono）** —— 工程感身份的刻意选择。
5. **功能型 pill/badge** —— 真实状态/标签，非装饰 spam。
6. **统一的封面模板** —— 系列辨识度所需（区别于 2.1 的"同节奏"，是必要的稳定性）。
7. **适度的高亮关键词** —— 一卡一处强调，服务于信息层级。

> 豁免项以**风格预设的 do/don't** 为准，二者叠加。

## 导出前自检清单（逐条核对）

- [ ] 尺寸 1080×1440；核心信息在安全区内（避底部 150px、四角）
- [ ] 一图一个观点；单卡 ≤60 字；短句
- [ ] 字号层级步进 ≥1.25×
- [ ] 单卡颜色 ≤3（1 accent + 1 highlight）；对比度达标
- [ ] 无编造数据 / 无绝对化用词
- [ ] 系列一致：字体 / 配色 / 间距 / 封面模板
- [ ] 缩略图（50%）可读
- [ ] 无 AI 生成感视觉：氛围渐变 / 光晕 / 玻璃 / 雾状大阴影 / 图标缸
- [ ] 未重画 OS/浏览器 chrome；界面用真实截图（或用最小 `.mock` 并告知）
- [ ] 封面 3 秒钩子；编号仅用于真实序列
- [ ] 无外链；已计划勾选 AI 生成声明
