# 设计系统（引擎规范）

`assets/core.css` 的说明文档。**引擎固定、风格可变**：本文件定义不变量与主题变量契约；风格预设只填变量，不改引擎。

---

## 1. 画布与安全区

| 项 | 值 | 说明 |
|----|----|------|
| 画布 | 1080 × 1440（3:4） | 图文信息流（小红书等）最优比例；导出 1× 即平台规格 |
| 内边距 | `--pad-x 84px` / `--pad-top 88px` / `--pad-bottom 76px` | 对称留白 |
| 安全区 | 底部 `--safe-bottom 150px`、四角 | 底部会被标题/头像遮挡；核心信息放中上 2/3 |
| 卡间距 | 页眉 `top` → 内容 `body` → 页脚 `foot` | 三段式骨架固定 |

> 成品是**图片**，不是网页：不涉及响应式/交互/滚动。所有卡片按固定像素渲染。

---

## 2. 类型比例（比例固定，绝对字号可按需微调）

| 角色 | class | 字号 | 备注 |
|------|-------|------|------|
| 封面主标 | `.cover-h1` / `.cover-h1--sm` | 128 / 108px | 2–3 行，短词，勿整句 |
| 卡片标题 | `.title` / `.title--xl` | 68 / 78px | |
| 正文 | `.lede` | 34px | 行高 1.78 |
| 列表标题/说明 | `.li__t` / `.li__d` | 36 / 29px | |
| tile | `.tile__v` / `.tile__d` | 34 / 26px | |
| 键位/命令 | `.key` / `.cmd` | 继承 | 等宽 |
| 角标/页脚 | `.eyebrow` / `.foot` | 24 / 22px | 等宽大写 |

**层级规则**：相邻层级步进 ≥1.25×，否则看不出主次。每卡最多 3 级（主标 > 副标 > 注释）。

## 3. 版式原子（组件库）

可复用的结构件；**不要发明与它们重复的新 class**。

- **壳**：`.card`（基础）· `.card--cover`（纸面封面）· `.card--cover-tint`（浅色着色封面）· `.card--dark`（可选深色重音）· `.card--cta`
- **顶栏**：`.top` + `.brand`（logo+名） + `.eyebrow`（mono 标签，`::before` 是短色条）
- **内容区**：`.body`（默认垂直居中）· `.body--top`（顶对齐）· `.body--gap`（块间距）
- **底栏**：`.foot` + `.foot__page`
- **标题群**：`.kicker` · `.cover-h1` · `.cover-sub` · `.title` · `.lede` · `.hr`
- **列表**：`.list` / `.li`（`.li__idx` 编号 / `.li__t` / `.li__d`）；5 行以上加 `.list--tight`
- **事实网格**：`.grid` / `.tile`
- **时间线**：`.timeline` / `.tl`（真实有序步骤才用编号）
- **提示块**：`.callout`（accent）/ `.callout--highlight`（第二色）
- **终端**：`.key` / `.keyline`（键位）· `.cmd`（内联命令）
- **截图**：`.shot`（真实截图框，**唯一允许承载界面**的容器）
- **概念示意**：`.mock`（命令面板示意；`.mock--compact`）——**最小化，非 OS chrome**
- **数据**：`.stat` / `.stat__num` / `.stat__unit`
- **CTA**：`.cta-box`（含 `__label/__main/__note/__cat`）
- **工具类**：`.mono .center .mt-8/20/24/32/44/56 .stack .gap-18/24/40`

**一卡一个焦点**：每张卡只允许一个视觉主角（大标题 / 截图 / 网格），其余为配角。

---

## 4. 发丝线与材质

- 结构用 **1px 发丝线**（`--rule` / `--rule-2`），而非色块或粗边框。
- 圆角统一小尺度（`--radius-sm 14` / `--radius 20` / `--radius-lg 24`）；嵌套时内圆角 = 外圆角 − 内边距（保持同心）。
- 阴影**克制、贴合元素**（`--shadow-card` / `--shadow-float`）；禁止大范围弥散"雾状"阴影。
- 封面可有一层极轻的点阵纹理（`::after`），仅封面使用。

## 5. 主题变量契约

引擎自带一组**默认主题 = tech-cobalt**；预设通过覆盖以下变量换皮。**只覆盖变量，不改引擎规则。**

> ⚠️ 未覆盖的变量会**静默回落** tech-cobalt。为避免风格混搭，一个预设应**完整覆盖「颜色组 + 字体组」**；`--dark` 与封面变体可按需覆盖。

```
覆盖清单（建议全套覆盖）：
  --paper --paper-2 --paper-3 --surface
  --ink --ink-2 --ink-3 --ink-4
  --rule --rule-2
  --accent --accent-2 --accent-soft --accent-line --accent-ink --accent-on-dark
  --highlight --highlight-soft --highlight-ink
  --font-display --font-body --font-mono
按需覆盖：
  --dark --dark-2 --dark-3 --dark-ink --dark-ink-2 --dark-rule   （深色重音；≤1 张卡使用）
  --cover-paper --cover-tint --cover-tint-glow --cover-paper-glow （封面底色变体）
  --ok
```

**配色硬约束**（所有风格通用）：
- 主色 70% + 强调 30%；单卡**≤3 个颜色**（中性不计入强调色预算）。
- 一个风格只有**一个 accent + 一个 highlight**；highlight 用量克制（数字/关键/CTA）。
- 禁止：高饱和霓虹、渐变文字、纯黑底大字（信息流太重）、浅字浅底。

---

## 6. 新增组件 / 修改引擎的规则

1. 先确认现有原子无法满足；**优先组合已有原子**。
2. 新组件只加在 `core.css`，用现有 token，不写死颜色/字体。
3. 不得修改本文件与 `core.css` 中已声明的**不变量**（画布/安全区/三段骨架/层级步进/发丝线）。
4. 改动后同步更新本文件第 3/4 节。

---

## 7. Do / Don't

| Do | Don't |
|----|-------|
| 一卡一个观点、一个焦点 | 一图塞多个观点、多主角 |
| 近白/中性底 + 单一 accent | 高饱和多色、霓虹、渐变文字 |
| 发丝线做结构 | 粗边框、色块堆叠 |
| 真实截图 | 手绘 OS/浏览器 chrome |
| 克制的贴合阴影 | 弥散"雾状"大阴影 |
| 层级步进 ≥1.25× | 标题≈正文的扁平层级 |
| 系列统一（色/字/间距/封面模板） | 各卡风格漂移 |
| 展示可核对的事实 | 编造数字/评价 |
